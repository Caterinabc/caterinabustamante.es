Procesador de imágenes

Mientras diseñaba desde cero un e-commerce para una empresa tradicional que se digitalizaba, encontré un cuello de botella en la preparación del catálogo: unas 1000 imágenes de producto debían cumplir las mismas especificaciones antes de publicarse. Con IA, construí una herramienta que procesa todo el lote en 4 minutos, se adapta a las especificaciones de cualquier plataforma y genera una imagen de superficie instalada cuando solo existen fotos de piezas sueltas.

El cuello de botella

Preparar cada imagen implicaba repetir las mismas cinco acciones. La tarea no necesitaba una decisión de diseño distinta por archivo, solo aplicar las mismas reglas de forma consistente, así que la traté como un problema de flujo de trabajo.

Por qué un script propio

El script tenía que resolver varias tareas a la vez, y ninguna herramienta las cubría todas.

  • Imágenes de superficie

    Ninguna de las herramientas que probé podía armar una imagen de superficie instalada a partir de varias piezas.

  • Control de completitud

    Ninguna comprobaba que todas las imágenes se hubieran procesado.

  • Configuración reutilizable

    Indicar los parámetros en un script era más simple que reconfigurar una herramienta cada vez.

Las reglas

El script se configura con las especificaciones de cada plataforma de e-commerce. Se consultan los requisitos de imagen de la plataforma y se indican como parámetros.

ParámetroEn este proyecto
Dimensiones1500 × 1500 px
Relación de aspecto1:1
FondoBlanco
FormatoJPG
Tamaño máximo de archivo300 KB
Calidad mínima50 (escala JPG)
CarpetasEntrada y salida en Google Drive

DecisiónCada imagen se escala sin deformarla y se centra en un lienzo cuadrado blanco. Todos los productos mantienen una escala coherente y no se notan diferencias de color con el fondo del sitio.

Hecho con IA

Desarrollé el script con ChatGPT en unas dos horas de iteración. Definí las reglas, probé el resultado con muestras reales y ajusté hasta que coincidió. El script ejecuta esta secuencia en cada archivo, con los parámetros configurados.

  1. EntradaCarpeta de DriveUnas 1000 fotos
  2. 01ConvertirAl formato definido
  3. 02RedimensionarSin deformar
  4. 03CentrarEn un lienzo blanco 1:1
  5. 04ComprimirSe repite hasta 300 KB
  6. 05VerificarCompara entrada y salida
  7. SalidaImágenes listasMás un informe de archivos faltantes

Verificación

Cada nombre de archivo incluía el SKU y el nombre del producto. Al terminar, el script compara la cantidad de imágenes y los nombres de archivo entre las carpetas de entrada y salida, e informa de cualquier producto que falte.

También revisé una muestra de las imágenes procesadas, elegida por tipo de pieza (cuadrada, rectangular e irregular), para comprobar el resultado visual. La muestra no tuvo errores.

Resultado

Estimé las 15 horas de trabajo manual a partir de una muestra de fotos que procesé a mano. Los 4 minutos de ejecución están medidos. Incluso contando el tiempo de desarrollo, la primera ejecución tomó una séptima parte del proceso manual.

Ejecuté el script varias veces y lo entregué al equipo de desarrollo y al cliente. No tengo datos de uso posteriores a la entrega.

La imagen de superficie instalada

En cerámica, los clientes necesitan ver el producto instalado, pero los proveedores solían enviar solo fotos de piezas sueltas. Añadí una función que arma una imagen de la superficie instalada completa a partir de esas piezas.

La disposición depende de las proporciones de la pieza, como en una instalación real:

El resultado se recorta a 1:1 para usar el mismo formato que el resto del catálogo. Si las piezas no llenan la última fila, el script repite piezas del mismo conjunto para completarla.

La imagen de superficie instalada es una referencia, y el cliente lo sabía.

Lo que aprendí

Este proyecto extendió mi trabajo de diseño al proceso de producción. Cuando una tarea exige las mismas decisiones cientos de veces, las convierto en reglas explícitas y las automatizo. La IA acelera el desarrollo, pero definir las reglas y validar el resultado siguen siendo trabajo de diseño.
